# Evaluación 2: Diseño de Página Web Básica

## Descripción del Proyecto
Este repositorio contiene la entrega para la Evaluación 2 de la unidad curricular de Diseño Web. El proyecto consiste en una página web personal ("Portfolio") creada desde cero utilizando **HTML5 Semántico** y **CSS en línea**, siguiendo estrictamente los requisitos académicos pero con un diseño moderno y "Premium".

## Contenido
El tema central del sitio es la **Inteligencia Artificial (IA)**, explorando conceptos como:
*   **LLMs (Large Language Models)**
*   **Ingeniería de Prompts**
*   **Vibecoding**

## Características Técnicas
*   **HTML5 Semántico:** Uso correcto de etiquetas `<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`.
*   **Estilos en Línea:** Todo el diseño visual está aplicado mediante atributos `style="..."`, sin hojas de estilo externas ni bloques `<style>` globales (excepto para animaciones críticas).
*   **Roadmap Interactivo:** Una sección animada que muestra la ruta de aprendizaje sugerida.
*   **Funcionalidades Extra:** 
    *   Botón para exportar el roadmap como imagen (usando `html2canvas`).
    *   Carrusel infinito con recomendaciones de recursos en YouTube.
